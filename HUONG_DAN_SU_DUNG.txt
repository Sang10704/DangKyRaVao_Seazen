1. GIOI THIEU:
Hệ thống phần mềm độc lập quản lý 4 máy chấm công kiểm soát cửa ZKTeco SenseFace 4A 
tại văn phòng SeaZen, không phụ thuộc vào ePAD hay bên thứ 3.

- 4 Thiết bị ZKTeco:
  + 172.16.56.139 : Làn VÀO phải (TCP 4370)
  + 172.16.56.138 : Làn VÀO trái (TCP 4370)
  + 172.16.56.137 : Làn RA trái (TCP 4370)
  + 172.16.56.136 : Làn RA phải (TCP 4370)

2. YEU CAU HE THONG TREN MAY CHAY (HOST):
- Hệ điều hành: Windows 10 / 11 / Windows Server
- Đã cài Python (khuyên dùng Python 3.10, 3.11 hoặc 3.12).
  LƯU Ý KHI CÀI PYTHON: Nhớ tích vào ô "Add Python to PATH".
- Máy tính phải cắm dây mạng LAN hoặc kết nối Wi-Fi cùng dải mạng thấy được IP 4 máy cửa (172.16.56.x).

3. CACH KHOI CHAY (1-CLICK DONG GOI SAN):
- Nhấp đúp chuột vào file: [ CHAY_HE_THONG_CUA.bat ]
- File này sẽ tự động:
  + Kiểm tra và tự cài đặt thư viện cần thiết (waitress, flask, pyzk, pyodbc, openpyxl...).
  + Tự động Ping kiểm tra kết nối tới 4 máy ZKTeco SenseFace 4A.
  + Tự động phát hiện IP của máy tính hiện tại.
  + Tự động giải phóng cổng mạng 6868 nếu bị kẹt.
  + Tự động bật máy chủ đa luồng Waitress và mở trình duyệt web.

4. CACH TRUY CAP:
- Tại chính máy chủ đang chạy: http://localhost:6868
- Từ máy Lễ tân / máy khác trong mạng LAN: http://<IP_MAY_CHU>:6868
  (IP máy chủ sẽ được hiển thị ngay trên cửa sổ đen của CHAY_HE_THONG_CUA.bat)
